# GREEN v2

Updated one-page lawn website with:

- Lawn Seed Calculator
- Fertilizer Calculator
- Seasonal Lawn Calendar
- My Lawn Journey
- Grass Types section
- Local image folder

## File structure

green_v2/
├── index.html
└── images/
    ├── prepared-soil.png
    ├── watering-process.png
    ├── first-seedlings.png
    ├── lush-lawn.png
    ├── reseeding-patches.png
    └── first-mowing.png

## How to publish

1. Open your GitHub repository.
2. Upload `index.html`.
3. Upload the entire `images` folder.
4. Commit changes.
5. Vercel will redeploy automatically.

## If you want to replace photos

- Upload your new images into the `images` folder.
- Keep the same names, or edit the image paths inside `index.html`.
